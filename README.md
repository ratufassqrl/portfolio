### 1. Oil Gestures — управление 3D-симулятором нефтяной скважины жестами

**Формат:** командный проект  
**Роль:** 3D-визуализация, UI и проработка интерактивного сценария

#### Задача

Создать систему распознавания жестов, с помощью которой пользователь управляет 3D-симулятором нефтяной скважины через веб-камеру.

#### Как работает продукт

`Камера → MediaPipe landmarks → распознавание жеста → команда → изменение 3D-сцены`

Камера считывает движения руки пользователя. MediaPipe определяет ключевые точки ладони, после чего распознаватель жестов преобразует их в команды для управления клапанами, манометрами, контроллером и уровнемером в 3D-сцене.

#### Мой вклад

- Разработала 3D-модели устьевой арматуры, контроллера и уровнемера
- Создала анимации для моделей оборудования
- Проработала логику работы нефтяной скважины
- Создала пользовательский интерфейс 3D-симулятора
- Участвовала в создании интерактивного сценария управления жестами

#### Результат

Получился интерактивный 3D-симулятор, в котором жесты пользователя вызывают наглядные изменения состояния оборудования. Проект показывает прикладное использование компьютерного зрения и ML в пользовательских интерфейсах.

**Технологии:** Python · MediaPipe · OpenCV · PyTorch · PySide6 · PyVista · CUDA/MPS · Blender

### 2. «Своя игра» — интерфейс многопользовательской викторины

**Формат:** frontend-проект  
**Роль:** разработка пользовательского интерфейса

#### Задача

Разработать понятный интерфейс для игроков и ведущего многопользовательской викторины: от подключения к игровой комнате и создания вопросов до финального раунда и отображения результатов.

#### Мой вклад

- Разработала экраны входа в комнату, ожидания начала игры и создания игры
- Создала игровой экран с отображением счёта и статуса вопроса
- Реализовала интерфейс финальных ставок и ввода финального ответа
- Настроила визуальные статусы: ожидание, доступность ответа, ответ игрока, верный ответ и принятая ставка
- Адаптировала интерфейс для мобильных устройств и компьютеров
- Тестировала удобство и функциональность визуальной части

#### Особенности

- Синхронизация интерфейса с игровыми событиями через WebSocket
- Мгновенная визуальная обратная связь при действиях игрока
- Адаптивная вёрстка для разных размеров экрана
- Отдельные сценарии для обычного и финального раундов

#### Результат

Создан динамичный игровой интерфейс, который помогает игроку и ведущему быстро понимать состояние игры и реагировать на открытие вопроса, ответы участников, изменение счёта и этапы финального раунда.

**Технологии:** HTML · CSS · JavaScript · WebSocket · адаптивная вёрстка

**Материалы:**

- [Исходный код](https://github.com/NordManul/svoya-igra)
- [Материалы по дизайну](https://disk.yandex.ru/d/rTiibxmfSFaI-g)

### 3. Changellenge >> Cup Russia 2026 — «Квадратные метры без сложностей»

**Формат:** командный кейс-чемпионат  
**Направление:** продуктовая стратегия и UX/UI-подход

#### Задача

Разработать стратегию привлечения аудитории до 35 лет в закрытые паевые инвестиционные фонды недвижимости управляющей компании «СФН». Цель команды — увеличить долю молодых пайщиков с 3% до 10% за три года.

#### Что сделала команда

- Сегментировала аудиторию: 18–24, 25–29 и 30–35 лет
- Выявила мотивацию и барьеры для инвестирования в ЗПИФ
- Провела конкурентный анализ инвестиционных сервисов
- Сформировала стратегию продвижения и продуктовых улучшений
- Подготовила дорожную карту инициатив и презентацию решения

#### Мой профессиональный фокус

В кейсе мне была особенно интересна продуктовая и UX/UI-часть: как через визуализацию, прозрачную подачу информации и понятный интерфейс объяснить молодой аудитории сложный инвестиционный продукт и снизить барьер входа.

#### Результат

Кейс развил навыки анализа аудитории, продуктового мышления, командной работы и защиты решений. Я увидела, как дизайн интерфейса влияет на доверие, понятность и вовлечённость пользователей.
